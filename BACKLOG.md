## 1. Конструктор автоматизаций: визуальная схема потока вместо стека блоков

**Статус:** раздел «Автоматизации» временно скрыт с фронта — фича-флаг
`AIOS_FEATURES.automations: false` в `frontend/js/api.js` (скрывает пункт
сайдбара, плитку на главной, секцию n8n в админке; прямой заход на
`automations.html` показывает заглушку). Вернуть видимость — переключить
флаг в `true`.

**Что не устроило:** текущий конструктор — стек блоков с формами, визуально
не похож на n8n. Для сотрудников, ждущих «доску с узлами», это барьер.

**Задача:** переработать конструктор в вертикальную схему потока —
карточки-ноды, соединённые стрелками (триггер → шаги), клик по ноде
открывает панель параметров. Реализация: ванильный JS + SVG-линии между
нодами, без шага сборки (стек проекта). Макет:

```
┌──────────────────────┐
│  ⏰ По расписанию    │   каждые 30 мин
└──────────┬───────────┘
           ▼
┌──────────────────────┐
│  🤖 Агент AIOS       │   «Сделай сводку…»
└──────────┬───────────┘
           ▼   {{prev}}
┌──────────────────────┐
│  ✉ Письмо            │   → user@inst.ru
└──────────────────────┘
```

**Следующий шаг после этого (отдельная задача):** полноценный canvas
(перетаскивание узлов, рисование связей мышью, зум) и ветвления
«если/иначе» — потребует расширения блочной модели в
`api/runtime/n8n_blocks.py` (сейчас цепочки линейные) и, вероятно,
canvas-библиотеки без сборки (Drawflow или своя на SVG).

**Что уже готово и не переделывается:** весь движок — бэкенд
(`api/routers/automations.py`, `api/runtime/n8n_*.py`,
`api/runtime/automations_store.py`), интеграция с n8n через public API,
шаг «ИИ-агент AIOS», деплой (`deploy/n8n/`), тесты (`tests/test_automations.py`,
`tests/test_n8n_settings.py`). Меняется только фронтенд конструктора:
`frontend/js/automations.js` (рендер стека → рендер схемы) и стили в
`css/style.css`.

**Критерий готовности:** пользователь собирает автоматизацию, видя поток
целиком (как на макете), без чтения документации; все существующие тесты
зелёные; флаг `AIOS_FEATURES.automations` переключён в `true`.
