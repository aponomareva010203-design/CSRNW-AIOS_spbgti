# Композит: правило смесей и удельные характеристики
> сравнить армирующие волокна или посчитать свойства композита по составу

## Порядок

1. Продольный модуль — правило смесей; поперечный — Халпин-Цаи.
2. Плотность — по объёмным долям.
3. **Обязательно удельные характеристики** (делённые на плотность).
4. Честный вывод: где замена оправдана свойствами, а где — другими причинами.

## Почему удельные обязательны

Более плотное волокно даёт больший абсолютный модуль просто потому, что его
больше по массе. По абсолютным цифрам картина систематически обманчива.
Конструктора интересует масса конструкции, то есть удельная жёсткость.

## Код

```python
Vf = 0.55
Em, rho_m = 3.2, 1.16       # матрица: ГПа, г/см3
fibers = {"базальт": (89.0, 2.67), "E-стекло": (73.0, 2.54)}

rows = []
for name, (Ef, rho_f) in fibers.items():
    E1 = Ef*Vf + Em*(1-Vf)                                  # продольный
    eta = (Ef/Em - 1)/(Ef/Em + 2)
    E2 = Em*(1 + 2*eta*Vf)/(1 - eta*Vf)                     # поперечный, Халпин-Цаи
    rho = rho_f*Vf + rho_m*(1-Vf)
    rows.append({"волокно": name, "E1_ГПа": round(E1,1), "E2_ГПа": round(E2,1),
                 "плотность": round(rho,2), "удельная_жёсткость": round(E1/rho,1)})
    print(f"{name:10} E1={E1:5.1f} ГПа  rho={rho:.2f}  E1/rho={E1/rho:.1f}")

base, alt = rows[0], rows[1]
gain = (base["удельная_жёсткость"]/alt["удельная_жёсткость"] - 1)*100
print(f"выигрыш по удельной жёсткости: {gain:+.0f}%")
result = {"варианты": rows, "выигрыш_удельной_жёсткости_%": round(gain,1)}
```

## Обязательная оговорка

Модуль волокна — справочный и имеет разброс (базальт 85–95 ГПа в зависимости
от состава породы и технологии вытяжки). **Назвать взятое значение и диапазон**,
иначе сравнение выглядит точнее, чем оно есть.

## Что сказать сверх чисел

Если выигрыш по удельным характеристикам в пределах 10–15 %, честный вывод —
паритет, и обосновывать замену надо независимостью от импорта или рабочей
температурой, а не свойствами. Так и сказать.
