# Теплообменный аппарат: площадь и выбор типа
> известны расходы, температуры и среды обеих сторон, нужна площадь или тип аппарата

## Порядок

1. Тепловая нагрузка Q по той стороне, где данные полнее.
2. Средний логарифмический напор LMTD.
3. Поправка F на схему тока. **F < 0,8 — схему менять**, сказать об этом явно.
4. Коэффициент теплопередачи k — расчётом или обоснованным справочным, с учётом загрязнения.
5. Площадь A = Q/(k·LMTD·F), запас 10–15 % (назвать, какой взят).
6. Выбор типа сравнением, а не по умолчанию.
7. Потери давления.

## Код (сигнатуры проверены на сервере)

```python
from ht import LMTD, F_LMTD_Fakheri
from CoolProp.CoolProp import PropsSI

Thi, Tho, Tci, Tco = 80.0, 40.0, 20.0, 35.0      # °C
V_h = 30/3600                                     # м3/с
U = 540.0                                         # Вт/(м2·К)

Tm = (Thi + Tho) / 2 + 273.15
rho = PropsSI('D', 'T', Tm, 'P', 2e5, 'Water')    # CoolProp — ТОЛЬКО кельвины
cp  = PropsSI('C', 'T', Tm, 'P', 2e5, 'Water')

Q = V_h * rho * cp * (Thi - Tho)
lmtd = LMTD(Thi, Tho, Tci, Tco)                   # (Thi, Tho, Tci, Tco, counterflow=True)
F = F_LMTD_Fakheri(Thi, Tho, Tci, Tco, shells=1)  # именно shells, не Nshell
A = Q / (U * F * lmtd)

print(f"Q={Q/1000:.0f} кВт, LMTD={lmtd:.2f} К, F={F:.3f}, A={A:.1f} м2, с запасом {A*1.15:.1f}")
result = {"Q_кВт": round(Q/1000, 1), "LMTD_К": round(lmtd, 2),
          "F": round(F, 3), "A_м2": round(A, 1), "A_с_запасом": round(A*1.15, 1)}
```

Контрольное значение: для данных выше A = 93,7 м² (проверено живым прогоном).

## Выбор типа — сравнением

| Тип | Когда брать | Когда не брать |
|---|---|---|
| Пластинчатый | чистые среды, p < 25 бар, важна компактность и цена | загрязнённые среды, высокое давление |
| Кожухотрубный | p до 100 бар, ремонтопригодность, загрязнение | когда критичны габариты и цена |
| Спиральный | вязкие и загрязнённые среды | сложная чистка, самый дорогой |
| Воздушного охлаждения | нет оборотной воды | ограничен температурой воздуха |

## Типовые ошибки

- `LMTD(dT1, dT2)` — **неверная сигнатура**, нужны четыре температуры.
- Забыть поправку F: для 1-2 хода она 0,85–0,92, площадь занижается на 10–15 %.
- Взять k «по опыту» без учёта загрязнения — занижение площади вдвое.
- Не проверить Δp: аппарат помещается, но насос не тянет.
