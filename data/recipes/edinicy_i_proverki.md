# Единицы измерения и проверки правдоподобия
> любой расчёт, где есть размерности — то есть почти всегда

## Правило

Ошибка в единицах — самый частый способ получить число, которое выглядит
разумно и неверно вдвое или в тысячу раз. Проверяйте размерность машиной,
а не глазами.

## Код

```python
from pint import UnitRegistry
u = UnitRegistry()

G = 30 * u.meter**3 / u.hour          # расход
rho = 983.2 * u.kilogram / u.meter**3
cp = 4185 * u.joule / (u.kilogram * u.kelvin)
dT = 40 * u.kelvin

Q = (G * rho * cp * dT).to(u.kilowatt)   # если размерности не сходятся — исключение
print(f"Q = {Q:.1f}")

result = {"Q_кВт": round(Q.magnitude, 1)}
```

## Обязательные проверки перед выдачей числа

| Проверка | Что означает провал |
|---|---|
| размерность сошлась (pint не упал) | формула собрана неверно |
| порядок величины правдоподобен | ошибка в переводе единиц |
| знак правильный | перепутаны вход и выход |
| результат меняется в нужную сторону при росте входа | ошибка в знаменателе |

## Быстрые ориентиры для химической технологии

- вода: ρ ≈ 1000 кг/м³, cp ≈ 4,18 кДж/(кг·К)
- органика: ρ 700–1400 кг/м³, cp 1,5–2,5 кДж/(кг·К)
- коэффициент теплопередачи: газ-газ 10–50, жидкость-жидкость 300–1500,
  с кипением/конденсацией 1000–4000 Вт/(м²·К)
- перепад давления в трубопроводе: разумно до 0,5 бар на аппарат
- если получилось «площадь теплообмена 5000 м²» или «время реакции 0,001 с» —
  ищите ошибку, а не радуйтесь

## Что делать при расхождении

Не подгонять. Сказать человеку: «получилось X, это на два порядка больше
ожидаемого, вероятная причина — Y, проверьте исходные данные Z».
