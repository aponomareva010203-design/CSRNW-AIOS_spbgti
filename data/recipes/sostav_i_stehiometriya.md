# Состав и стехиометрия рецептуры
> нужно посчитать массы компонентов: связующее, отвердитель, наполнитель, партия

## Порядок

1. Стехиометрия реакционных компонентов по эквивалентам, не «на глаз».
2. Перевод массовых долей в объёмные — там, где свойства зависят от объёма.
3. Баланс на партию с запасом на потери (назвать, какой взят).
4. Проверка переработываемости: вязкость, жизнеспособность, время цикла.
5. Себестоимость — **только если даны цены**; нет цен — сказать, чего не хватает.

## Эпоксидные системы

```python
EEW = 195.0     # г/экв, эпоксидный эквивалент смолы (из паспорта)
AHEW = 24.3     # г/экв, аминный эквивалент отвердителя
m_resin = 100.0

m_hard = m_resin / EEW * AHEW
print(f"на {m_resin:.0f} г смолы: {m_hard:.1f} г отвердителя "
      f"(рабочий диапазон {m_hard*0.9:.1f}–{m_hard*1.1:.1f} г)")

# массовая доля -> объёмная
w_fill, rho_fill, rho_matrix = 0.40, 3.95, 1.16
V_fill = (w_fill/rho_fill) / (w_fill/rho_fill + (1-w_fill)/rho_matrix)
print(f"наполнитель: {w_fill:.0%} масс. = {V_fill:.1%} об.")

# вязкость с наполнителем (Кригер-Догерти), phi_max ~0.62 для сфер
eta_rel = (1 - V_fill/0.62)**(-2.5*0.62)
print(f"вязкость вырастет примерно в {eta_rel:.1f} раза")

result = {"отвердитель_г": round(m_hard,1), "наполнитель_об_%": round(V_fill*100,1),
          "рост_вязкости": round(eta_rel,1)}
```

## Пороги переработываемости

| Способ | Предел вязкости | Что делать при превышении |
|---|---|---|
| Вакуумная инфузия | ~1 000 мПа·с | подогрев, снизить наполнение, сменить способ |
| RTM | ~3 000 мПа·с | подогрев формы |
| Ручная выкладка, заливка | ~10 000 мПа·с | — |

## Типовые ошибки

- Считать отвердитель по массовым процентам из чужой рецептуры: эквиваленты
  зависят от конкретной марки, расхождение до 30 %.
- Путать массовые и объёмные доли при расчёте свойств — ошибка в полтора раза.
- Забыть жизнеспособность: состав пригоден, но не успевает залиться.
