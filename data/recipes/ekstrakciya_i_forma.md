# Экстракция растительного сырья и твёрдая форма
> подобрать экстрагент, посчитать состав таблетки, проверить прессуемость

## Часть 1. Подбор экстрагента

Целевые вещества → нужная полярность → система растворителя.

| Класс веществ | Параметр Гильдебранда δ, МПа^0,5 | Подходит |
|---|---|---|
| Эфирные масла, каротиноиды | 16–19 | гексан, сверхкритический CO2 |
| Флавоноиды, фенолокислоты | 22–27 | этанол 50–70 % |
| Сапонины, гликозиды | 28–32 | вода-этанол, NADES холин-глицерин |
| Полисахариды | > 33 | вода, щелочная вода |

Для NADES: вязкость чистой системы часто 300–1200 мПа·с, что непрактично.
Разбавление водой 20–30 % снижает вязкость в разы, полярность держится в окне.
**Всегда указывать долю воды.**

## Часть 2. Состав таблетки

```python
dose_mg, content = 25.0, 0.12        # доза действующего и его доля в экстракте
tablet_mg = 500.0

extract = dose_mg / content
print(f"экстракта на таблетку: {extract:.0f} мг ({extract/tablet_mg:.0%} массы)")

rest = tablet_mg - extract
composition = {"сухой экстракт": extract,
               "МКЦ (наполнитель, прессуемость)": rest*0.52,
               "лактоза (наполнитель)": rest*0.26,
               "кроскармеллоза Na (распадаемость)": rest*0.17,
               "аэросил (скольжение)": rest*0.032,
               "магния стеарат (антиадгезия)": rest*0.018}
for k, v in composition.items():
    print(f"  {k:42} {v:6.1f} мг")

bulk, tapped = 0.42, 0.58            # насыпная и утрясочная плотность, г/см3
carr = (tapped - bulk)/tapped*100
hausner = tapped/bulk
verdict = ("прямое прессование" if carr < 16 else
           "гранулирование или смена наполнителя" if carr > 25 else "пограничная текучесть")
print(f"индекс Карра {carr:.0f}%, Хауснер {hausner:.2f} -> {verdict}")

result = {"состав_мг": {k: round(v,1) for k,v in composition.items()},
          "индекс_Карра": round(carr), "Хауснер": round(hausner,2), "вердикт": verdict}
```

## Пороги текучести

| Индекс Карра | Хауснер | Текучесть | Вывод |
|---|---|---|---|
| < 16 % | < 1,19 | хорошая | прямое прессование |
| 16–25 % | 1,19–1,34 | средняя | требует проверки |
| > 25 % | > 1,34 | плохая | влажная грануляция обязательна |

## Обязательное

Контроль по фармакопее: распадаемость, однородность массы и дозирования,
прочность, остаточные растворители. Для NADES отдельно — остаточное
содержание компонентов экстрагента в готовой форме.
