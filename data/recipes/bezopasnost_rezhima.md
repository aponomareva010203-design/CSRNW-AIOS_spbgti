# Безопасность режима: экзотерма и тепловой разгон
> экзотермическая реакция, работа под давлением, масштабирование объёма вверх

## Зачем

При масштабировании тепловыделение растёт как объём, а теплоотвод — как
поверхность. Режим, безопасный в колбе, может стать неуправляемым в
реакторе. Это считается ДО эксперимента, а не после.

## Порядок

1. Тепловой эффект реакции ΔH и адиабатический разогрев ΔT_ад.
2. Время разгона (TMR) при рабочей температуре.
3. Отношение поверхность/объём для лабораторного и целевого масштаба.
4. Требуемая мощность теплосъёма против фактической.
5. Вердикт и меры: разбавление, дозирование, снижение T, проточный режим.

## Код

```python
import math

dH = 95e3          # Дж/моль, экзотермический эффект (минус = выделение)
c0 = 2.0           # моль/л
cp_v = 1900e3      # Дж/(м3·К) объёмная теплоёмкость среды
V_lab, V_target = 0.5e-3, 100e-3     # м3
Ea, k0, T_work = 85e3, 1e9, 353.0    # кинетика и рабочая T, К
R = 8.314

dT_ad = abs(dH) * c0 * 1000 / cp_v
print(f"адиабатический разогрев: {dT_ad:.0f} К -> конечная {T_work-273.15+dT_ad:.0f} °C")

k = k0 * math.exp(-Ea/(R*T_work))
q = abs(dH) * k * c0 * 1000                  # Вт/м3
def sv(V):  # поверхность/объём для сферы того же объёма
    r = (3*V/(4*math.pi))**(1/3)
    return 3/r

print(f"тепловыделение {q/1000:.0f} кВт/м3")
for name, V in (("лаборатория", V_lab), ("целевой", V_target)):
    U = 300.0
    q_out = U * sv(V) * 20     # съём при перепаде 20 К
    print(f"  {name}: съём {q_out/1000:.0f} кВт/м3 -> "
          f"{'ЗАПАС' if q_out > q*2 else 'ОПАСНО: съём не покрывает' }")

result = {"dT_адиабат_К": round(dT_ad), "тепловыделение_кВт_м3": round(q/1000)}
```

## Пороги

| Показатель | Значение | Вывод |
|---|---|---|
| ΔT_ад | > 50 К | обязательно дозирование или разбавление |
| ΔT_ад | > 200 К | температура достигнет разложения — режим неприемлем |
| конечная T | выше T кипения при рабочем давлении | риск вскипания и выброса |
| съём / выделение | < 2 | запаса нет, разгон при любом отказе охлаждения |

## Обязательная оговорка

Это **скрининговая оценка**, а не расчёт промышленной безопасности. Она
показывает, где нельзя, но её вывод «можно» не заменяет экспертизу,
калориметрию (DSC/ARC) и HAZOP. Так и говорить человеку.
