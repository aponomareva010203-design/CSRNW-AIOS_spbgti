# Гидравлика и смешение в канале
> проточный или микрореакторный процесс: подобрать геометрию, проверить режим, посчитать потери

## Порядок

1. Пересчитать производительность в объёмный расход.
2. Подобрать диаметр и длину под требуемое время пребывания.
3. Re — режим течения. При ламинарном смешение только диффузией.
4. Время диффузионного смешения. **Если > 10 % от времени реакции — нужен смеситель**, сказать явно.
5. Число Дина для змеевика: вторичные вихри резко ускоряют смешение.
6. Потери давления и требование к насосу.
7. Число параллельных каналов под производительность, с запасом.

## Код

```python
from fluids import Reynolds, friction_factor, K_from_f, dP_from_K
import math

Q = 3.5e-6/60          # м3/с (3,5 мл/мин)
d = 0.8e-3             # м
L = 1.2                # м
rho, mu, D_ab = 950.0, 2.5e-3, 1e-9

A = math.pi*d**2/4
V = Q/A
tau = L/V
Re = Reynolds(V=V, D=d, rho=rho, mu=mu)
fd = friction_factor(Re=Re)
dP = dP_from_K(K_from_f(fd=fd, L=L, D=d), rho=rho, V=V)

t_mix_diff = d**2/(4*D_ab)             # диффузионное смешение поперёк канала
R_coil = 5e-3
De = Re*math.sqrt(d/(2*R_coil))        # число Дина

print(f"V={V*1000:.1f} мм/с, tau={tau:.0f} с, Re={Re:.0f}, De={De:.0f}")
print(f"dP={dP/1e5:.2f} бар, время смешения диффузией={t_mix_diff:.1f} с")
result = {"tau_с": round(tau,1), "Re": round(Re), "De": round(De),
          "dP_бар": round(dP/1e5,2), "t_смешения_с": round(t_mix_diff,1)}
```

## Пороги

| Величина | Значение | Что означает |
|---|---|---|
| Re | < 2300 | ламинарный: без смесителя не обойтись |
| Re | > 4000 | турбулентный: смешение быстрое |
| De | > 30 | вторичные вихри, смешение ускоряется на порядок |
| t_смеш / tau | > 0,1 | смешение лимитирует, результат невоспроизводим |
| Δp | > 3 бар | пересмотреть диаметр или число каналов |

## Типовые ошибки

- Считать время пребывания по объёму реактора без учёта распределения:
  в ламинарном потоке центр идёт вдвое быстрее стенки.
- Масштабировать увеличением диаметра: теряется вся выгода микроканала.
  Масштабировать **числом параллельных каналов**.
