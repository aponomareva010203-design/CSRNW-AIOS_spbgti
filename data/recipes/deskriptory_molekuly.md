# Дескрипторы молекулы и скрининг вариантов
> перебрать варианты структуры, посчитать свойства, отсеять непроходные

## Порядок

1. Получить структуры: `compound_lookup` (PubChem) — не брать SMILES из памяти.
2. Посчитать дескрипторы через rdkit.
3. Применить фильтры того класса веществ, с которым работаете.
4. Выдать таблицу с ЯВНЫМ основанием отсева по каждой строке.
5. Сверить с литературой: какие варианты преобладают в опубликованных работах.

## Код

```python
from rdkit import Chem
from rdkit.Chem import Descriptors, Crippen, rdMolDescriptors as rdmd

def props(smiles):
    m = Chem.MolFromSmiles(smiles)
    if m is None:
        return None
    return {"MW": round(Descriptors.MolWt(m),1),
            "cLogP": round(Crippen.MolLogP(m),2),
            "TPSA": round(rdmd.CalcTPSA(m),1),
            "HBD": rdmd.CalcNumHBD(m), "HBA": rdmd.CalcNumHBA(m),
            "вращ_связи": rdmd.CalcNumRotatableBonds(m),
            "ароматич_колец": rdmd.CalcNumAromaticRings(m)}

for s in ["CC(C)(C1=CC=C(C=C1)O)C2=CC=C(C=C2)O"]:
    print(s[:40], props(s))
result = {"свойства": props("CC(C)(C1=CC=C(C=C1)O)C2=CC=C(C=C2)O")}
```

## Фильтры по классам

| Класс | Ориентиры |
|---|---|
| Малые молекулы (правило пяти) | MW ≤ 500, cLogP ≤ 5, HBD ≤ 5, HBA ≤ 10 |
| «За пределами правила пяти» (PROTAC, макроциклы) | MW 700–1100, cLogP ≤ 7,5, TPSA 150–250, вращ. ≤ 32 |
| Пищевые и косметические | смотреть растворимость и стабильность, не проницаемость |
| Мономеры и добавки | реакционные группы, температура кипения, летучесть |

Пороги — **эмпирика, а не закон**. Говорить «не проходит по эмпирическому
критерию», а не «работать не будет».

## Чего этот расчёт НЕ даёт

Активность, селективность, токсичность. Дескрипторы — только физико-химическая
проходимость. Обещать биологию по ним нельзя, и надо прямо это сказать.
