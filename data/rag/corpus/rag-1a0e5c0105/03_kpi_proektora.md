# Карта показателей офиса проректора по инновациям

> Шаблон системы KPI. Значения задаются вузом; формулы — рекомендации для дашборда
> «Рабочий стол проректора».

## Уровни показателей

1. **Результат** — что вуз получил: доходы от РИД, выручка компаний, внебюджет.
2. **Поток** — насколько полна воронка: уведомления о РИД, заявки, стартапы, пилоты.
3. **Эффективность** — конверсии и сроки: доля патентов с лицензиатом, срок от
   уведомления до решения, конверсия стартап-студии.

## Показатели

| Блок | Показатель | Формула / источник |
|---|---|---|
| РИД | Уведомления о РИД за год | Реестр ЦТТ |
| РИД | Доля патентов с лицензиатом | Патенты с договором / все действующие патенты |
| РИД | Затраты на поддержание без лицензиата | Сумма пошлин по патентам без договора |
| Проекты | Проекты по УГТ | Распределение портфеля по уровням 1–9 |
| Проекты | Проекты-кандидаты на закрытие | На одном УГТ ≥ 2 лет |
| Проекты | Средний срок перехода между УГТ | По датам перехода |
| Стартапы | Стартапы в студии по этапам | Воронка студии |
| Стартапы | Привлечено внешних средств стартапами | Гранты + инвестиции |
| МТК | Число действующих МТК / компаний по лицензии | Реестр МТК |
| МТК | Выручка МТК | Отчёты МТК |
| Финансирование | Цепочка «наука → грант → студия → венчур» | Деньги по стадиям |
| Финансирование | Внебюджет от НИОКР с индустрией | Бухгалтерия |
| Люди | Студенты в акселераторах | Платформа УТП |
| Люди | Защиты «Стартап как диплом» | Учебный отдел |

## Ритм управления

- **еженедельно** — трекер обязательств венчурного билдера (риски, просрочки);
- **ежемесячно** — воронка стартап-студии, новые РИД и заявки;
- **ежеквартально** — портфель по УГТ, решения по застрявшим проектам, отчёты МТК;
- **ежегодно** — ревизия патентного портфеля, план KPI, отчёт по программе развития.
