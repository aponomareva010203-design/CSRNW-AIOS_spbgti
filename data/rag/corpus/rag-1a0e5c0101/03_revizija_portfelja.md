# Ревизия патентного портфеля вуза

> Методика для ЦТТ и проректора по инновациям. Пороговые значения — ориентиры для
> обсуждения на комиссии по ИС, а не нормативные требования.

## Зачем нужна ревизия

Патент — это не только актив, но и регулярные расходы: пошлины за поддержание растут с
каждым годом действия, а большая часть вузовских патентов не лицензируется. Ежегодная
ревизия высвобождает бюджет на перспективные РИД и снимает с баланса «мёртвые» активы.

## Критерии оценки каждого патента

1. **Коммерческий интерес** — есть ли лицензиат, переговоры, запросы партнёров за 2 года.
2. **Связь с живыми проектами** — используется ли РИД в проекте портфеля, стартапе, МТК.
3. **Технологическая актуальность** — не устарело ли решение, есть ли аналоги лучше.
4. **Стоимость поддержания** — пошлины на ближайшие 3 года и их доля в бюджете ЦТТ.
5. **Стратегическая ценность** — ключевая компетенция вуза, ПИШ, «Приоритет-2030».
6. **Оборонительная функция** — защищает ли патент ядро технологии стартапа.

## Шкала решений

| Балл | Решение |
|---|---|
| Высокий интерес + связь с проектом | Поддерживать, активно лицензировать |
| Средний интерес, связи нет | Поддерживать 1 год, вывести на маркетплейсы технологий |
| Низкий интерес, рост пошлин | Предложить авторам / партнёрам (отчуждение) |
| Нет интереса 3+ лет, не связан с проектами | Отказ от поддержания |

## Признаки «кандидата на отказ»

- патенту больше 5 лет, лицензиата нет и не было;
- не используется ни в одном проекте портфеля;
- авторы не заинтересованы в выкупе;
- годовые пошлины выше медианы портфеля.

На дашборде «Рабочий стол проректора» такие патенты помечены как «низкая перспективность».
Агент «Портфельный аналитик» формирует по ним список с обоснованием для комиссии.

## Процедура

1. Выгрузка реестра РИД с датами, пошлинами и привязкой к проектам.
2. Анкета авторам: планы использования, контакты заинтересованных компаний.
3. Скоринг по шести критериям, ранжирование.
4. Заседание комиссии по ИС, протокол решений.
5. Уведомление авторов о решении не поддерживать патент (с предложением выкупа).
6. Обновление реестра и бюджета пошлин на следующий год.
