Модели

Модели, которыми пользуется офис проректора по инновациям. Модели офиса проректора — прозрачные расчётные модели для решений по портфелю: считаются прямо на странице, без LLM. Модели проектов — расчётные приборы, обученные на данных проектных команд. Открытые модели — каталог открытых весов на Hugging Face для агентов, RAG-поиска и прогнозов KPI.

Модели офиса проректора

Демо-модели с экспертными коэффициентами: каждая показывает вклад каждого фактора в результат. Откалибруйте коэффициенты на данных своего вуза (frontend/js/innovation_models.js) или обучите свою модель проекта.

Модели проектов доступны администраторам

Создание, обучение и импорт моделей проектов сейчас открыты только администраторам платформы. Модели офиса проректора и каталог открытых моделей доступны всем.

Модели проектов

Расчётные приборы, обученные на опытах проектных команд: входы с единицами → результат с погрешностью, которую платформа проверила на опытах, не участвовавших в обучении.
