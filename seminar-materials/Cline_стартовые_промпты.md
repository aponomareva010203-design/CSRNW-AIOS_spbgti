# Доработка платформы AIOS с помощью Cline: стартовые промпты

Памятка для участников сессии. Cline — ИИ-помощник в VS Code. Вы пишете ему
задачу обычными словами, он сам меняет файлы платформы и показывает каждое
действие. Правила работы с этой платформой Cline берёт из файла `.clinerules`
в папке платформы. Его не нужно открывать или менять.

Все задачи ниже проверены на этой версии платформы: изменения сделаны по
правилам `.clinerules` и проверены в браузере и автотестами.

## Перед началом (5 минут)

1. Запустите платформу двойным щелчком: `start_windows.bat` (Windows) или
   `start_mac.command` (Mac). Не закрывайте чёрное окно.
2. Откройте в VS Code папку платформы: «Файл → Открыть папку».
3. Откройте панель Cline (значок слева) и проверьте, что модель подключена:
   ключ выдают организаторы.
4. Сохраните исходную версию — первый промпт:

```
Сохрани текущую версию платформы, чтобы я мог к ней вернуться: если папка
ещё не под git — инициализируй git и сделай коммит «исходная версия».
```

## Как работать

- **Одна задача — один промпт.** Дождитесь, пока Cline закончит, и проверьте
  результат в браузере. Только потом переходите к следующей задаче.
- **Сначала план.** Cline покажет план — прочитайте его. Если что-то не то,
  поправьте словами: «не надо трогать меню», «цифры возьми такие».
- **Разрешения.** Cline спрашивает разрешение на правку файлов и команды.
  Нажимайте «Approve», если действие соответствует плану.
- **Проверка.** Обновите страницу с полной перезагрузкой: Ctrl+F5 (на Mac —
  Cmd+Shift+R). Если Cline сказал, что нужен перезапуск, закройте чёрное окно
  и снова запустите платформу двойным щелчком.
- **Квадратные скобки** в промптах — места, куда подставить своё. Скобки
  уберите.

## Разминка. Знакомство с платформой (5 минут)

Ничего не меняет — помогает понять, где что лежит.

```
Объясни простыми словами, из каких разделов состоит платформа AIOS и в каких
файлах лежат данные рабочего стола проректора. Ничего не меняй.
```

## 1. Данные своего вуза на рабочем столе (10 минут)

**Что получится:** дашборд покажет название и цифры вашего университета.

```
Замени в данных рабочего стола проректора название университета на
«[Название вуза]» и поменяй три проекта портфеля на наши:
1) [название проекта], [факультет], УГТ [число], на этом уровне с [месяц год],
   бюджет [сумма] млн ₽;
2) ...;
3) ...
Остальные демо-данные оставь.
```

**Проверка:** «Рабочий стол проректора» → Ctrl+F5 → в заголовке ваш вуз, в
таблице «Портфель по УГТ» — ваши проекты.

**Если не видно:** нажмите на дашборде «Вернуть демо-данные». Раньше
загруженный файл перекрывает данные из папки платформы.

## 2. Новая плитка показателя (10 минут)

**Что получится:** ещё одна плитка в ряду KPI над дашбордом. Значение
считается по уже имеющимся данным.

```
Добавь на рабочий стол проректора плитку KPI «Средний срок на одном УГТ»:
среднее по всем проектам портфеля число лет на текущем уровне готовности,
в годах с одним знаком после запятой. Подсвечивай плитку красным, если
среднее больше порога «кандидата на закрытие». Все плитки должны остаться
в одном ряду.
```

**Проверка:** Ctrl+F5 → в ряду плиток появилась «Средний срок на одном УГТ»,
например «1,8 г.».

**Ещё идеи:** «Доля патентов с высокой перспективностью, %», «Бюджет портфеля
на стадии „Венчур“».

---

## 3. Новый виджет с графиком (20 минут)

**Что получится:** новый блок на дашборде со столбчатой диаграммой и
подсказками при наведении.

```
Добавь на рабочий стол проректора виджет «Доход от лицензий по годам»:
столбчатая диаграмма по годам 2022–2026, над каждым столбцом сумма, при
наведении — число лицензионных сделок за год. Данные добавь новым блоком
в данные дашборда, заполни правдоподобными демо-цифрами и подпиши, что это
демо-данные. Виджет — на всю ширину, перед трекером венчурного билдера.
```

**Проверка:** Ctrl+F5 → внизу дашборда новый виджет с пятью столбцами.
Наведите мышь на столбец — появится подсказка.

**Дальше:** «Замени демо-цифры в виджете доходов от лицензий на наши:
2022 — [сумма] тыс. ₽, [число] сделок; …».

**Ещё идеи:** «Заявки на гранты ФСИ по годам: подано / поддержано»,
«Студенты в акселераторах по институтам».

---

## 4. Новый раздел в меню (25 минут)

**Что получится:** новая страница с таблицей и фильтром и пункт в левом меню
на всех страницах.

```
Сделай новый раздел «Индустриальные партнёры» в группе «Каталоги» левого
меню: таблица компаний (название, отрасль, контактное лицо, число сделок,
статус: лицензиат / заказчик НИОКР / переговоры) и кнопки-фильтры по
отрасли над таблицей. Данные — отдельным файлом, заполни 5 демо-компаниями
и подпиши, что данные демонстрационные.
```

**Проверка:** Ctrl+F5 → в меню слева появился пункт «Партнёры» на любой
странице. Раздел открывается, фильтр по отрасли работает.

**Дальше:** «В разделе „Партнёры“ добавь над таблицей поиск по названию
компании» или «добавь колонку „Сумма договоров, тыс. ₽“».

**Ещё идеи:** «Реестр МТК вуза», «Календарь конкурсов и грантов»,
«Эксперты для экспертного совета».

---

## 5. Новое поле в карточке проекта (15 минут)

**Что получится:** в карточке проекта и в форме её правки появится новое
поле. Его начнёт спрашивать и агент онбординга.

```
Добавь в карточку проекта поле «Индустриальный партнёр» (до 300 символов):
показывай его в карточке и в форме редактирования. Пусть агент онбординга
спрашивает о нём на шаге про рынок и клиента для стартапов.
```

**Проверка:** **нужен перезапуск платформы** — закройте чёрное окно и
запустите снова. Затем «Проекты» → откройте проект → «Редактировать» →
заполните «Индустриальный партнёр» → «Сохранить» → поле видно в карточке.
Проектов пока нет? Сначала пройдите онбординг: «Кабинет» → «Создать новый
проект».

**Ещё идеи:** «Источник финансирования следующего этапа», «Куратор проекта
от вуза».

---

## 6. Свой агент (15 минут)

**Что получится:** новый агент в каталоге «Агенты». Его можно запустить
в рабочем чате.

```
Создай агента «Навигатор мер поддержки» в разделе шаблонов: он уточняет у
пользователя УГТ проекта, состав команды и есть ли юрлицо, ищет подходящие
меры поддержки в базе знаний «Меры поддержки» и выдаёт таблицу: мера,
оператор, требования, что сделать до подачи. Размеры грантов и сроки не
выдумывает — только из базы знаний, с оговоркой проверить актуальное
положение конкурса.
```

**Проверка:** «Агенты» → раскройте «Шаблоны агентов для управления инновациями» →
карточка «Навигатор мер поддержки». Запустите его в рабочем чате (нужен
подключённый LLM) и спросите: «Студенческая команда, УГТ 3, юрлица нет —
куда подаваться?».

**Ещё идеи:** «Секретарь экспертного совета», «Аналитик патентного
портфеля нашего института».

---

## 7. Свой пример полигона (15 минут)

**Что получится:** новый пример в «Полигонах» с вашей гипотезой и
сценариями.

```
Добавь пример полигона «„Стартап как диплом“: рост студенческих стартапов».
Гипотеза: если разрешить защищать ВКР в форме стартапа, за 4 года появится
не меньше 5 стартапов. Сценарий «Стартап как диплом»: приток новых проектов
в год вдвое больше базового, больше выходов через компании, а не лицензии.
Идея для ИИ-фокус-группы — короткое описание этой меры. Остальные параметры
возьми из примера про стартап-студию.
```

**Проверка:** «Полигоны» → Ctrl+F5 → новая карточка → «Запустить
симуляцию» → видно, в какой доле прогонов гипотеза подтверждается.

**Дальше:** «Добавь в этот полигон сценарий „Стартап как диплом +
стартап-студия“ и сравни».

---

## 8. Карточка в новом чате (10 минут)

**Что получится:** новая подсказка в блоке «Чем займемся сегодня» на
стартовом экране рабочего чата.

```
Добавь в «Чем займемся сегодня» в новом чате карточки «Найти партнёра»
(индустриальный заказчик или лицензиат для технологии), «Письмо
партнёру» (черновик письма о сотрудничестве) и «Протокол совещания»
(протокол по тезисам). Иконки — в стиле остальных карточек.
```

**Проверка:** Ctrl+F5 → «Новый чат» → среди карточек появились новые.
Нажмите карточку — в поле ввода подставится начало фразы.

## Если что-то пошло не так

**Страница пустая или кнопка не работает:**

```
После твоей правки [что не работает, на какой странице]. Вот что в консоли
браузера (F12 → вкладка Console): [вставьте красный текст или приложите
скриншот]. Найди и исправь причину.
```

**Платформа не запускается после правки:**

```
Платформа не запускается после последней правки. Вот текст из чёрного окна:
[вставьте текст или приложите скриншот]. Исправь ошибку.
```

**Cline не может починить за 2–3 попытки — откатитесь:**

```
Откати все изменения последней задачи и верни платформу к последней
сохранённой версии. Потом предложи, как сделать эту задачу меньшими шагами.
```

Ещё способ откатиться: у каждого шага в Cline есть кнопка «Restore» —
возврат к состоянию до этого шага.

**Удачная доработка — сохраните версию:**

```
Сохрани текущую версию платформы коммитом «[что сделано]».
```

## Своя задача

Когда освоитесь, формулируйте задачи сами по схеме:

> **Что** добавить или изменить → **где** (страница, раздел, виджет) →
> **какие данные** (свои или демо) → **как должно выглядеть или работать**.

Пример: «На странице „Проекты“ добавь над карточками фильтр по типу проекта:
все / стартапы / управленческие инициативы».

Большую идею сначала обсудите с Cline: «Хочу [идея]. Предложи план из
небольших шагов, ничего пока не меняй».
